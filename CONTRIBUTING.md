# Contributing to PraxisIQ

Thank you for your interest in contributing! We welcome contributions from everyone.

## Ways to Contribute

- **Report bugs** – Find and report issues you encounter
- **Suggest features** – Share ideas for improvements
- **Improve documentation** – Help make docs clearer
- **Write tests** – Increase code coverage
- **Fix bugs** – Submit pull requests with fixes
- **Add features** – Implement new functionality

## Getting Started

1. **Fork the repository** on GitHub
2. **Create a branch** for your changes (`git checkout -b feature/your-feature`)
3. **Make your changes** with clear commits
4. **Write or update tests** if applicable
5. **Update documentation** as needed
6. **Submit a pull request** with a clear description

## Development Setup

1. Clone your fork
2. Create a virtual environment
3. Install dependencies
4. Create a `.env` file with test credentials
5. Make your changes
6. Test thoroughly

## Pull Request Guidelines

- **Clear title** – Describe what you're fixing or adding
- **Detailed description** – Explain the changes and why
- **Link issues** – Reference related issues with `#123`
- **Test your code** – Ensure changes work
- **Keep commits clean** – Use meaningful commit messages
- **One feature per PR** – Keep pull requests focused

## Code of Conduct

Be respectful and inclusive. We're all here to learn and grow together.
